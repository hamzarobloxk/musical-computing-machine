# AeroReach Media

Landing page for AeroReach Media (aeroreachmedia.com). A single static `index.html` with no build step.

- Three.js and GSAP load from cdnjs.
- The contact form posts to Web3Forms. The access key is set near the top of the script (`WEB3FORMS_KEY`).
- Contact email: hamzaosman@aeroreachmedia.com

## Deploy on Vercel

1. Import this repo in Vercel.
2. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
3. Deploy, then add `aeroreachmedia.com` under Project Settings > Domains.
